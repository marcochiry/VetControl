 Descripción del proyecto: Aplicación de escritorio desarrollada en C# utilizando Windows Forms (.NET) para la gestión y 
 el registro de pacientes en una clínica veterinaria. Permite registrar datos de mascotas, calcular edades en meses, 
 clasificar etapas de vida, aplicar tarifas con descuentos e impuestos, y administrar listas de registros de manera interactiva.

        Instrucciones de UsoClonar o descargar el repositorio en tu equipo local.
        Abrir la solución VetControl.slnx o el archivo de proyecto .csproj utilizando Visual Studio (.NET 8 o superior).  
        Compilar la solución para asegurar que las referencias y dependencias carguen correctamente.
        Ejecutar la aplicación (presionando F5 o el botón verde de inicio).
        Ingresar los datos solicitados en los campos de texto correspondientes y hacer clic en Agregar para registrar la información en el sistema.
